# 数模侠线上桌游

第一版用于大创答辩演示：朋友创建或加入六位房间号，AI 补齐，秘密身份、夜晚技能、六种公式、公投、出局答题及结算在同一个服务端执行。保留原 v4.0 实体卡面，不修改项目原始资料。

## 现在如何玩

1. 双击本目录的 **启动桌游.cmd**，保留弹出的服务窗口。
2. 浏览器打开 **http://127.0.0.1:8787**。
3. 输入昵称，创建8人房。另一名玩家用另一个浏览器或无痕窗口加入，输入房间号。
4. 房主点“用 AI 补齐并开局”。只在轮到自己时行动，白天在聊天区发言，点击结束发言后轮到下一位。

当前机器已存在 Node.js 24；不需要 npm install。新电脑需安装 Node.js 24 或以上。

让同一 Wi-Fi 的另一台设备参加，使用 **启动局域网.cmd**，地址改为电脑局域网 IP，例如 `http://192.168.1.23:8787`（示例地址，需替换为真实 IP）。不能把电脑上的 `127.0.0.1` 发给手机。手机麦克风需要可用的安全连接；局域网 HTTP 先测试文字对局。

## 微信端

项目在 `wechat/`。它是实际调用同一服务的 Canvas 客户端，没有独立计算胜负或预设演示结果。开发者工具导入时选择小游戏项目，替换账号的 AppID，并将 `wechat/config.js` 中的后端地址改为可达的 HTTPS 域名。普通小程序与小游戏类目最终须在微信官方后台确认，不把“微信内打开网页”算作原生微信端完成。

浏览器与微信客户端均支持身份、座位、技能、公式、文字发言、录音识别、题目与结算；但开发者工具/协议模拟不能代替真实手机端体验版验收。

## 文件与维护

- `server/game.mjs`：规则状态机、个人视图和全部行动校验。
- `server/http.mjs`：同房API、会话、动作幂等、AI调度和音频。
- `server/ai.mjs`：模型输入隔离、合法动作、规则降级和月预算。
- `public/`：响应式网页与原卡面。
- `wechat/`：微信端Canvas界面和统一API客户端。
- `tests/`：规则、同房、持久化、AI隐私、语音并发与跨端协议测试。
- `.data/`：运行时房间、会话、音频和应用估算费用。不要把这个目录上传或发给他人。
- `docs/`：设计、计划、规则裁定和接入验收说明。

运行测试：`node --test tests/*.test.mjs`。本轮36项通过；完整证据与未验证内容见 **[验收记录](docs/验收记录.md)**。源码没有服务密钥，`.env` 和运行数据已被忽略。

## 规则与题库说明

使用说明书修订版v2叠加v4.0增补，SVD沿用吞噬。开发者对模糊条款的实现裁定在 **[规则裁定](docs/规则裁定.md)**，可供团队后续调整。50道题来自实体卡内容；原卡“π小数点后第5位”答案误写为5，线上修正为9，原文件未改。专业题采用结论/方法选答，不声称自动检查证明。

该版本是单进程演示服务。若部署多进程或多实例，必须先换共享数据库与并发控制，不能复制启动多个进程假装支持横向扩容。
