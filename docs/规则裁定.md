# 线上规则裁定

基础是《说明书修订版v2》与《卡牌清单与规则增补v4.0》，不是旧README中已过期的人数表。以下是开发者为使模糊规则可执行而作的裁定，未改动原文档；后续可由团队调整。

| 项目 | 当前执行方式 |
|---|---|
| SVD能力 | 每夜可吞噬一名本夜出局者的阵营；不获得神职角色名；本夜已确定出局的SVD不行动 |
| 大数翻牌 | 首次公投免死一次，保留投票权；猎人带走不触发翻牌 |
| 守护与救药 | 同一目标守护优先，不消耗救药；不能自守或自救；同夜可救毒 |
| 异常刀人 | 可提名任何存活者，多数决，平票随机；不把同伴提名公开给其他阵营 |
| 公式牌池 | 六种各三张，每人一张；同种每白天至多生效一次，使用后丢弃 |
| 拉格朗日 | 双方从系统记录的真实信息中各选一条，也可公开自身阵营；双方确认才扣牌；拒绝或超时不扣牌；机器人被拒后本日不重复邀请 |
| 傅里叶 | 公投锁定后、执行死亡前提供8秒窗口；唯一最高票免死，次高替代；次高平票重投；受保护者在本次公投重投中仍免于淘汰 |
| 黎曼 | 指定已出局者在下一轮白天获得一次额外遗言，不恢复身份能力或投票，不重复答题 |
| 自爆 | 白天可用，出局技能与答题遗言完成后跳过剩余白天进入黑夜 |
| 出局顺序 | 处理猎人连锁→各出局者答题→遗言→胜负判定；终局出局者也有答题机会 |
| 平票 | 补充发言后最多重投一次，再平票为平安日；允许弃票，不可投自己 |
| 题库 | 20冷知识+30专业唯一题，一局不重复；专业题改为结论/方法选答，不声称证明已自动判定 |
| 原卡笔误 | π小数点后第5位由错误的5修正为9；只修线上答案，原PDF与deck.py保留 |
| 语音形式 | 轮流发言时发送录音，识别后确认文字；首版没有多人持续语音通话 |

原模拟器把预言家查出的异常自动公开给好人，这只是模拟策略；线上版已移除此行为，查验结果只给查验者，由玩家自行决定是否公开。

模拟胜率不作为本版已平衡的证据。需要真实试玩数据及玩家水平标定后再讨论平衡。
